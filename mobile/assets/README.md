# App assets for Capacitor

Place source images here, then run from the repo root:

```bash
npm run mobile:assets
npm run mobile:sync
```

## Required files

| File | Size | Notes |
|------|------|-------|
| `icon-only.png` | 1024×1024 | App icon, transparent or solid background |
| `splash.png` | 2732×2732 | Optional centered logo on brand color |

Brand color: `#1e40af` (DocuLink primary blue)

After adding `icon-only.png`, run the asset generator to produce Android and iOS icon/splash sets.
